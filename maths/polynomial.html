Polynomials in mathmatics refer to a general set of functions that meet the following criteria:

  • Must contain at least one term.
  • Must not have infinate terms
  • Criteria for a term: Must not contain the following: division of variables, or negative exponentials
  • Can contain multiple variables (x, y, z)
  • Does not require a variable

$$f(x)=x^3-4x^2$$

Polynomials have a number of key parts that can be found, just by looking at them. The degree of a polynomial is largest exponent that is attached to a variable in the equation. An exmaple of this is on the example equation on the right, were $x$ is to the power of 3. This is the largest exponent in the polynomial is 3 so this is the degree. While we are talking about exponentials and polynomials it might be useful to mention standered form. Standered form of a polynomial is quite simple, the terms are ordered highest exponential to lowest exponential. If two terms have the same exponent then simply order them by thier coefficent (variables come before non variables).

There are methods of finding the x intercepts, the shape of the function, and any y intercepts. This guide will go over them.

Note that the x intercepts can only be found if the polynomial is in factored form or is a quadratic. This guide covers what factored form is but does not go over how to factor. For a guide on this, go here:

Polynomial guide

Factored form varies from equation to equation but looks something like this: $$(x+2)\cdot(x-2)$$ Solving for the x intercepts in factored form is very simple. All you need to do is set each linear term equal to zero and solve for x.
This is shown on the right.

If an equation is in the standered quadratic form ($ax^2+bx-c$, or similar), the quadratic formula can be used to solve for the x intercepts. The quadratic formula looks something like this:
$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$ If the equation is in standered quadratic form, $ax^2-bx-c$, where $a$, $b$, and $c$ are constents (not variables) simply plug them into the quadratic formula and solve. Example on the right.

Next up is the y intercept. This one is super easy because a function can only cross $y=0$ once (or any y point for that matter). To solve for the y intercept of any polynomial or function just set it equal to zero. Simple example:
$$f(x)=x+1$$ $$0=x+1$$ $$x=-1$$ The y intercept here is -1.

Finaly lets talk about function shape. A functions shape can be determaned just by looking at it and by doing almost no math. Take the function:
$$(x+4)^2(x+1)$$
I know that this function will come up from $-\infty$ and bounce off the graph at 4, then strikethrough at 1. Finally it will accend into the heavens and go up forever ($\lim x \to \infty$). Did I cheat and look at a graph? Nope!

The first thing that I did was find the x intercepts. This is essential to know when finding the shape because you need to know where the line intercepts the x intercept to make an accurate graph with labeled points. The next thing I did is look at the number of x's in the equation. There are three when all the exponents are expanded out ($(x+4)^2=(x+4)(x+4)$) and this ment that both lines that infinately extend would extend in opposite directions (think of a linearish function). I knew this because there were three and three is an odd number. When you have an odd number of x's in the equation the line must extend in opposite directions. When you have an even nunber of x's in the function both ends of the line must extend in the same direction. The way a function behaves when it extends infinatly is known as end behavior Then I looked at what power each linear term was set to. The one that was $(x+4)^2$ to an even power so I knew it would bounce off the x intercept. The other linear term only had one x so I knew that it would strike through the x intercept. And I know what x intercept points the linear terms were tied to so I just corresponded those with the fact that if they bounced or not.

$$example$$ $$f(x)=x^3-4x^2$$

$$factoring\ example$$ $$(x+2)\cdot(x-2)$$ $$x+2=0$$ $$x=-2$$ $$x-2=0$$ $$x=2$$ $$The\ x\ intercepts\ are\ (2,0)\ and\ (-2,0)$$

$$Quadratic\ Example$$ $$x^2 - 5x + 6 = 0$$ $$a=1$$ $$b=-5$$ $$c=6$$ $$Plug\ In$$ $$x=\frac{5\pm\sqrt{-5^2-4\cdot 1 \cdot 6}}{2\cdot1}$$ $$x=\frac{5\pm\sqrt{25-24}}{2}$$ $$x=\frac{5\pm\sqrt{1}}{2}$$ $$x=\frac{5\pm1}{2}$$ $$Solve\ for\ both\ +\ and\ -$$ $$x=\frac{5+1}{2}$$ $$x=\frac{6}{2}$$ $$x=3$$ $$x=\frac{5-1}{2}$$ $$x=\frac{4}{2}$$ $$x=2$$ $$The\ X\ intercepts\ are\ 3\ and\ 2$$

Practice Problem/Real World Example: The insanity roller coster

How many times the roller coster is at zero feet.
Does the roller coster ever go underground?
Where the roller coster is coming from and where it is going (end behavior).

$Answear$ The roller coster touches the ground three times. The roller coster touches the ground at 2, -2, and 8. The roller coster never goes underground. The roller coster comes from $\infty$ and goes to $\infty$
